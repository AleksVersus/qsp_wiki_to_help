# Архив важного контекста проекта

Краткая выжимка долгосрочных технических решений и исторических фактов из бывших
`handoff.md` и `plan.md`. Актуальные команды и рабочие инструкции находятся в `README.md`;
этот файл — архив, не план работ.

## Архитектурные решения

- Основной инструмент — пакет `qsp_help_builder`, настройки читаются из обязательного
  внешнего `qsp_help.toml`; значения конфигурации не должны незаметно подменяться
  дефолтами в коде.
- Wiki-вход и Docusaurus Markdown-вход — независимые конвейеры. Не создавать
  искусственные wiki HTML, `sidebar` или `help_keywords` для Markdown-источника.
- Wiki-конвейер сохраняет прежние команды, модель, JSON-контракты `anchors.json` и
  `urls_links_to_files.json`. Новые Markdown-выходы изолированы в
  `.build/docusaurus_markdown/{chm,spa,pwa}`; не использовать `.build/chm`,
  `.build/spa` или отслеживаемый `docs/`.
- CHM компилируется внешней программой HTML Help Workshop; автоматическая компиляция
  `.chm` не входит в проект.
- DokuWiki-конвертер `docu_at_wiki/qspdocuwiki` был только внешним образцом строгой
  обработки и валидации. Его код не переносился; генератор DokuWiki в этом проекте
  не реализован.

## Docusaurus Markdown: зафиксированный объём

- Исходный snapshot, прошедший аудит: `QSPFoundation/qspfoundation.github.io`,
  commit `98db28531de1769d6036bc0dc998d90ffffd52de`.
- Выбор страниц задаётся вручную в `docusaurus_markdown/pages.json`: 62 активные
  `.md`-страницы, с исключёнными заглушками; TOC задаётся отдельно в `toc.json`.
  Новые страницы источника не должны автоматически попадать в выбранный корпус.
- Ссылки на `help_qspider_standalone.md` и `glossary_snippet.md` оставляются обычным
  текстом посредством `unlinked_excluded`; сами страницы не входят в модель и TOC.
- Поддерживается проверенный поднабор Markdown, не произвольный MDX/JSX. Raw HTML,
  MDX import/export, admonitions, setext headings, H5/H6 и неизвестные code fences
  должны выдавать диагностику, а не теряться молча.
- Историческая приёмка этого snapshot: 62 страницы, 576 ссылок, 9 локальных ассетов,
  8 plain-text-ссылок на исключённые заглушки.

## Бейзлайн и изменения поведения

- Исторический CHM baseline снимался на commit `914e503` в `_baseline/2026-10-16`;
  позже отдельный baseline создан в `_baseline/2026-10-17`. Отслеживаемый `html_out`
  исходно содержал ручные правки: код воспроизводил 71 из 73 файлов; различались
  `help_qgen.htm` и четыре цели в `qsp.hhk`. Поэтому старое «golden» нельзя считать
  чистым результатом исходного кода без проверки.
- В ранней фазе рефакторинга legacy-поведение и расхождения намеренно удерживались,
  чтобы не сдвигать baseline. В последующих документированных изменениях исправлены:
  имя DokuWiki media из `media=` вместо схлопывания в `fetch.png`, селектор футера
  `div.docInfo`, согласованная 0-based адресация anchors и воспроизводимость CHM.
- `[chm.keyword_overrides]` временно добавлялся для ручных переходов указателя, затем
  удалён: адреса уже корректно вычислялись через `anchors.json` и `href_compare`.
  Не возвращать override без нового подтверждённого случая.
- После изменений legacy-выходов сверять их с соответствующим датированным baseline;
  не применять историческую заметку о сохранении бага как текущее требование.

## Историческая передача

Фазы 0–8 wiki-конвейера и фазы 0–6 Docusaurus Markdown-входа были отмечены завершёнными
в handoff на 2026-11-22. Детали устаревших фаз, промежуточные реализации и чек-листы
не сохранены намеренно: их заменяют исходный код, тесты, `README.md` и baseline-артефакты.
